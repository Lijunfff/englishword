# 📊 工作英语学习

基于 PET Phonics 模板定制的个人工作英语词汇学习 PWA 应用。

## 功能

- **单词表** — 7 大分类浏览，支持搜索和进度标记
- **闪卡** — 翻转学习，认识/不认识按钮，不认识的单词自动循环
- **翻翻乐** — 记忆配对游戏
- **测验** — 选择题测试
- **记录** — 学习进度统计

## 词汇分类

| 分类 | 词汇数 |
|------|--------|

| 📋 日常办公 | 8 |

| 👔 职业合规 | 4 |

## 部署

该应用是纯静态 HTML + PWA，部署到 GitHub Pages 即可在任意设备访问。
